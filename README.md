# Дзеркало MBTI

Тип особистості очима друга та самооцінка: 91 твердження за шкалою від −3 до +3, кімната з кодом на двох учасників, результат у стилі liquid glass.

Один статичний файл — [`index.html`](index.html), без збірки й залежностей. Кімната працює через публічний сервіс [ntfy.sh](https://ntfy.sh) (без власного сервера); будь-хто, хто знає код кімнати, може прочитати відповіді в ній.
